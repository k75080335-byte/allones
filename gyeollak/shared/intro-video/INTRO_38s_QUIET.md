# 결락 인트로 B — 38초 「물속의 정적」 (모드 A 에디토리얼 + D 엔딩)

곡: `GYEOLLAK intro v2` (Suno, 38.8초). 조용히 시작해서 두 번 부풀었다 가라앉고, 한 번 멈춘 뒤 넓게 열렸다가 숨을 쉬고 닫힌다.
느낌: 잔잔하고 슬프다. 45초짜리와 같은 세계지만 달리지 않는다. 물과 빛 속에서 각자 혼자 있다가 마지막에 같은 물 위에 선다.

- 16:9, 1920×1080 이상. 컷 단위 생성 → 편집. 생성 오디오 끔.
- 사이트 심연(3번) 자리에 들어갈 인트로는 이 버전을 추천: 수면 → 빛 → 물가 → 물속 순서가 곡 구조와 그대로 맞는다.
- 담배·총 없음. 커플 연출 없음. 은은한 메이크업(글로스·펄 없음).

## 공통 블록

```text
FORMAT: Cinematic editorial band intro, generated per shot, cut to music in edit
ASPECT RATIO: 16:9 · RESOLUTION: 1920x1080 or higher · AUDIO: off
GENRE: Quiet underwater melancholy. Solitude that becomes togetherness.
STYLE: Premium cinematic realism, soft 35mm grain, slight halation, deep DOF falloff.
Palette: ink-navy mist, one cold beam of light per scene, deep teal water, white light panels.
The flower of each member is the only saturated colour. Match the existing member stills:
navy haze, single skylight or diagonal beam, figure small and full-body in wide shots.
No beauty filter, no glossy skin, no lip gloss, no shimmer.

REFERENCE LOCK
@taejun / @yuseong / @jinwoo / @ryuhyun = exact face, hair, anatomy, skin. Never swap faces.
@wardrobe = suit set chosen for the intro (sheet). Same garments in every shot of a member.
@taejun_still / @yuseong_still / @jinwoo_still / @ryuhyun_still = opening frames
(the four navy stills: water surface / light / waterside / underwater). Continue each directly.

HEIGHT LOCK
Moon Taejun 195cm — the tallest. Chae Yuseong 190cm. Ha Jinwoo 189cm. Chae Ryuhyun 188cm.
In shared frames: same ground or water plane, no forced perspective, Taejun's head clearly
above the others; the other three nearly level, each ~1cm lower. Never re-proportion a body.

PERFORMANCE CORE
Found, not posed. One small physical contact per shot — fingers on water, a petal missed,
a hand reaching toward light. Cut before it completes.
```
