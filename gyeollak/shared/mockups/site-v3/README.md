## 규칙 확인
- 영상은 동시에 하나: 히어로 영상은 히어로를 벗어나면 멈춤, 먹 영상은 재생 없이 스크롤로만 감김, 멤버 영상은 한 요소를 옮겨 씀, 미리 듣기 재생 시 다른 미디어 정지.
- 캔버스는 히어로 WebGL 하나뿐. 나머지는 CSS scroll-driven(`view()`)·clip-path·mask.
- 전환은 모두 오른쪽 위 모서리 번짐. 금붕어는 잔상(목록 9%, 12m 9%)만.
- 모션 줄이기/JS 없음: 모든 장면이 정지 이미지로 쌓여 보임(먹 영상 제외).
