## 콘셉트
缺落 = 떨어져 나가다. 스크롤 = 하강. 위(구름) → 아래(심연).

| 단계 | 스크롤 | 화면 |
|---|---|---|
| 01 HIGH CLOUD | 0–14% | 먹구름(fbm 노이즈) + 번개 깜빡임 + 빗줄기 |
| 02 FALL | 14–33% | 빗방울 하나가 떨어지고 수평선(검은 수면)이 올라옴, 수면에 구름 반사 |
| 03 SURFACE | 33–60% | 부딪히는 순간 섬광 + 데이터모시 글리치 → 위에서 본 검은 수면, 파문 속에서 백합이 핌. 뒤에 Gyeollak 세리프가 파문·꽃잎에 굴절 |
| 04 UNDER | 60–76% | 수면선이 화면을 지나 올라가고, 물 아래에서 올려다본 흐린 꽃 + 커스틱 빛 + 기포 |
| 05 ABYSS | 76–100% | 꽃이 방울로 흩어졌다가 ㄱㄹ로 모임 |

## 기법
- WebGL 프래그먼트 셰이더 1장 (`js/descent.js`), 외부 라이브러리 없음
- 꽃: 2D 캔버스로 그린 절차적 백합 2종 — X-RAY(잎맥·필름 입자) / GLASS(코발트 유리)
- 스캔 박스: 박스 안만 반대 모드로 렌더 (RAFXYM 레퍼런스)
- 글리치: 충돌·수면 통과 순간 + 스크롤 속도에 비례하는 블록 데이터모시 + 색수차 (보내준 백합 영상 레퍼런스)
- HUD: ALT/DEPTH·TEMP·STATE·SCAN 실시간, 세로 깊이 눈금, 조준선 (ICE HIBISCUS 레퍼런스)
- 하단 버튼: X-RAY ↔ GLASS 전환
